# MedTimer (Android)

ADHD med timer: log a dose, see how long it lasts, get eat / drink / wear-off reminders as phone notifications.

- The APK is built automatically by GitHub Actions on every push → see **Releases → latest → MedTimer.apk**.
- UI: `app/src/main/assets/index.html` (WebView). Native side: AlarmManager + notifications with Done / Snooze.
